# Slide 2
Navigasi adalah proses perpindahan pengguna dari satu halaman atau layar ke halaman lain dalam aplikasi mobile.
Contohnya, pengguna berpindah dari halaman login ke halaman beranda, dari beranda ke halaman profil, atau dari daftar produk ke detail produk.
Routing adalah mekanisme yang mengatur jalur atau alamat dari setiap halaman dalam aplikasi. Routing membantu aplikasi mengenali halaman mana yang harus ditampilkan ketika pengguna melakukan aksi tertentu.
Dengan kata lain, navigasi berfokus pada perpindahan layar, sedangkan routing berfokus pada pengaturan jalur halaman.

Stack Navigation
Stack navigation bekerja seperti tumpukan halaman. Ketika pengguna membuka halaman baru, halaman tersebut ditambahkan ke atas tumpukan. Jika pengguna menekan tombol kembali, aplikasi akan kembali ke halaman sebelumnya.
Contoh:	Login → Home → Detail Produk

Nested navigation adalah navigasi bertingkat, yaitu gabungan dari beberapa jenis navigasi. Misalnya, aplikasi menggunakan bottom navigation, tetapi setiap tab memiliki stack navigation sendiri.

TM12: State Management Dasar

1. Membuat Bloc: Anda mulai dengan membuat kelas Bloc yang mengelola state aplikasi. 
Ini biasanya terdiri dari dua bagian utama: event dan state. Event adalah tindakan yang 
memicu perubahan state, sedangkan state adalah keadaan terkini dari aplikasi.
2. Mengirim Event: Ketika ada tindakan yang memengaruhi state aplikasi, seperti
menekan tombol, Anda mengirimkan event ke Bloc.
3. Memproses Event: Bloc akan menerima event dan memprosesnya sesuai dengan logika
bisnis yang ditetapkan. Ini bisa berarti mengubah state, memanggil API, atau
melakukan tugas lainnya.
4. Menghasilkan State Baru: Setelah memproses event, Bloc akan menghasilkan state 
baru sesuai dengan perubahan yang terjadi.
5. Mengupdate UI: UI akan mengamati perubahan state dan secara otomatis diperbarui
untuk mencerminkan state terbaru. Ini dapat dicapai dengan menggunakan widget 
BlocBuilder atau widget serupa.
