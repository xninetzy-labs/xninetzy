## 51. Final Report

The final report must state:

```text
OBJECTIVE
STATUS
AUTONOMOUS ACTIONS
TOOLS
SKILLS
SOURCES
FILES
ARTIFACTS
TESTS
SECURITY FINDINGS
EXTERNAL ACTIONS
AUTHORIZATION BOUNDARIES ENCOUNTERED
WARNINGS
UNCERTAINTIES
CHECKPOINT
NEXT ACTION
```

Do not report unnecessary internal reasoning.

Report evidence and execution facts.
