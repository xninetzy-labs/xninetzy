# Assignment Orchestration

## Retrieve

Retrieve official:

* wording;
* course;
* deadline;
* rubric;
* template;
* materials;
* allowed resources;
* deliverable;
* submission state.

Inspect local files.

## Requirement matrix

| Requirement | Official source | Planned output | Status | Risk |
| ----------- | --------------- | -------------- | ------ | ---- |

Do not draft while critical requirements remain unknown.

## Work breakdown

Separate:

* assignment analysis;
* research;
* implementation;
* calculation;
* section writing;
* integration;
* citation audit;
* artifact generation;
* QA;
* optional submission.

## Validate

Check every requirement and rubric item.

For code:

* run tests;
* inspect output;
* verify reproducibility.

For artifacts:

* verify physical file;
* inspect content;
* inspect render when possible.

## Submission

Submission is not implied by "help me do this".

Use:

```text
prepare
-> preview
-> explicit confirmation
-> execute
-> verify
-> receipt
```
