# HEBAT academic workflow

Treat HEBAT as the learning-material and assignment connector, not as the whole Learning OS.

1. Verify the authenticated HEBAT session.
2. Sync courses or assignments when freshness is insufficient.
3. Read the requested course, activity, deadline, or material through typed tools.
4. Download files only into the configured HEBAT downloads directory.
5. Ingest or summarize material only after confirming the file was obtained.
6. Connect relevant material to a roadmap, concept, task, or review checkpoint.

For upload or submission:

1. Prepare the intended file and target activity.
2. Show the exact action and consequence.
3. Request approval through the existing HITL boundary.
4. Revalidate the activity before committing.
5. Preserve evidence of the result.

Never expose credentials, cookies, or browser state. Never claim a submission succeeded without portal confirmation.
