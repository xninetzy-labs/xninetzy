# hebat-academic — §34–36

## 34. Mastery Evidence

Distinguish:

```text
activity completed
≠
concept mastered
```

Possible evidence:

* assignment completion
* correct answer
* lecturer feedback
* revision quality
* repeated successful application
* assessment result
* demonstrated explanation

A submission alone should not automatically increase mastery confidence.
