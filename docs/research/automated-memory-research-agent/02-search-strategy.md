# 02 — Search Strategy

## Strategi umum
1. Round 1: petakan terminologi + bukti fondasional (Ebbinghaus, Bloom, Karpicke-Roediger, Cepeda, Dunlosky, VanLehn, Ma, Kulik-Fletcher).
2. Round 2: state of the art 2023-2026 (LLM memory, MemGPT/mem0/LOCOMO, agentic RAG, GraphRAG, research agents, N-BEATS/FSRS, knowledge tracing).
3. Verifikasi metadata: judul/penulis/tahun/venue/DOI lewat paper_research (semantic, crossref, openalex, arxiv, dblp) — jangan mengarang DOI.
4. Kategori sumber: original research, systematic review/meta-analisis, buku klasik, dokumentasi resmi, standar; YouTube hanya pendukung.

## Query per tema
- T1 Learning science: "spaced repetition", "retrieval practice testing effect", "Ebbinghaus forgetting curve", "desirable difficulties", "cognitive load theory", "self-regulated learning metacognition"
- T2 ITS & adaptive: "intelligent tutoring system meta-analysis", "adaptive learning system", "knowledge tracing deep learning", "learner modeling mastery learning"
- T3 LLM memory: "LLM memory long-term agents", "MemGPT", "mem0", "LOCOMO language model memory", "memory-augmented neural networks", "generative agents memory"
- T4 RAG & Graph: "retrieval-augmented generation", "agentic RAG", "graph RAG", "knowledge graph education"
- T5 Research agents: "AI research agent workflow", "autonomous literature review LLM", "agent orchestration"
- T6 Evaluasi & etika: "LLM education evaluation", "privacy LLM education", "AI bias education", "human-in-the-loop AI"

## Inclusion
Peer-reviewed (jurnal/konferensi), systematic review, buku akademik, dokumentasi resmi proyek (MemGPT, mem0, FSRS, GraphRAG), laporan institusi (UNESCO/OECD jika relevan), 2023-2026 untuk state of the art.

## Exclusion
Blog umum sebagai klaim akademik utama, preprint tanpa verifikasi untuk klaim krusial (boleh dikutip sebagai preprint dengan label), pseudo-sains.
